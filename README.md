# 📊 Business Administration & Data Intelligence Analytics Portfolio
**PT Vinix Seven Aurum (VINIX7) – MSIB Internship Program**

Selamat datang di repository portofolio analisis data saya! Repository ini berisi kumpulan **10 Studi Kasus** komprehensif yang dikembangkan selama menjalani program **Magang MSIB** sebagai **Business Administration Intelligence Analyst** di **PT Vinix Seven Aurum (VINIX7)**. 

Portofolio ini menampilkan penerapan end-to-end teknik pembersihan data, pengolahan logika bisnis, pemodelan data relasional, hingga perancangan dasbor eksekutif interaktif menggunakan **Microsoft Excel** dan **Power BI**.

---

## 🛠️ Tech Stack & Alat Analisis

- **Core Analytics Tool**: Microsoft Excel (Advanced Formulas, Dynamic Arrays, PivotTable, Power Query, Power Pivot)
- **Business Intelligence**: Power BI (DAX, Data Modeling, Dynamic Dashboards)
- **Database Concept**: Relational Data Schema, Data Integrity, ETL Workflows

---

## 📂 Ringkasan Modul & Studi Kasus

Repository ini terbagi ke dalam 10 modul utama yang mencakup berbagai aspek administrasi bisnis dan analisis data:

| Modul | Nama Kasus / Topik Utama | Deskripsi & Fokus Analisis |
| :---: | :--- | :--- |
| **01** | **Data Foundation for Business Administration** | Strukturisasi data mentah, validasi tipe data, dan standar dokumentasi tabel bisnis. |
| **02** | **Excel Lookup, Logic & Business Formulas** | Implementasi rumus logika bisnis kompleks (`INDEX-MATCH`, `XLOOKUP`, `NESTED IF`) untuk otomasi kalkulasi. |
| **03** | **Data Cleaning & Data Quality Assurance** | Pembersihan data ganda, penanganan *missing values*, serta standardisasi format data transaksional. |
| **04** | **PivotTable & PivotChart Reporting** | Agregasi data penjualan dan operasional secara cepat menggunakan PivotTable & PivotChart interaktif. |
| **05** | **Operational, HR & Financial Analytics** | Analisis performa sumber daya manusia, efisiensi operasional, dan laporan arus kas/biaya. |
| **06** | **Excel Automation & Administrative Workflows** | Efisiensi alur kerja administratif memanfaatkan otomasi template dan formula dinamis. |
| **07** | **KPI Monitoring & Visual Alert System** | Perancangan indikator kinerja utama (KPI) dengan sistem *conditional formatting* / visual alert otomatis. |
| **08** | **Power Query for Advanced Data Transformation** | Proses Extract, Transform, Load (ETL) untuk menggabungkan dan membersihkan multi-sumber data. |
| **09** | **Power Pivot, Data Modeling & DAX** | Pembentukan skema data relasional (Data Model) dan pembuatan ukuran kustom dengan kalkulasi DAX. |
| **10** | **Executive Dashboard & Power BI Reporting** | Penyusunan dasbor eksekutif interaktif dan visualisasi laporan bisnis menggunakan **Power BI** untuk mendukung pengambilan keputusan berbasis data (*Data-Driven Decision Making*). |

---

## 📌 Sorotan Utama Portofolio (Key Highlights)

1. **Flexibility & Stability**: Penggunaan struktur `INDEX-MATCH` dan fungsi pencarian modern untuk menjaga stabilitas rumus pada dataset berskala besar.
2. **Data Cleaning & ETL**: Penerapan **Power Query** untuk mentransformasi data mentah yang berantakan menjadi tabel siap analisis secara efisien.
3. **Advanced Modeling & DAX**: Penggunaan **Power Pivot** untuk menghubungkan berbagai tabel transaksional serta membuat formula DAX untuk kalkulasi metrics bisnis.
